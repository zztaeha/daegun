daegun's credits

daegun's own code is under the MIT license in LICENSE. This file holds the rest,
in two parts:

- Shipped in daegun: the notices of the code and data daegun carries from
  others. Their licenses ask software shipping daegun to ship these notices
  too, as the release archives and `cargo cinstall` do.
- Thanks: those whose work daegun was built and tested with.

THANKS

daegun was built and tested with these:

- fontTools, which builds the font fixtures daegun's tests read.
- text-rendering-tests, whose test fonts daegun's tests read.
- Viktor Chlumský, whose master's thesis on multi-channel signed distance
  fields gave daegun's MSDF its method: edges colored at corners, the median
  of three channels and their pseudo-distances. daegun's code is its own.
- The test fonts' designers. Each font's license sits beside it in
  assets/test-fonts.
