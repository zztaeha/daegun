test_glyphs_variable_no_cycle_test_glyphs.ttf   ../colr-v1-test-glyphs/
                                                  test_glyphs_variable.ttf,
                                                  minus 2 of 200 base glyphs.

Same Apache-2.0 license as ../colr-v1-test-glyphs/LICENSE.txt – content
removed, nothing added. The original's COLR table has two deliberately
cyclic PaintColrGlyph entries named "paintcolrglyph_cycle_first"/
"paintcolrglyph_cycle_second" (gids 178/179), an adversarial case for
renderers to reject. Real sanitizers (confirmed via Google's own
`ots-sanitize`, same code Chromium runs) refuse the entire COLR table over
it, taking down every other glyph in the file along with it – including
gid 116 ("translate_100_0"), which is genuinely valid and has zero
relation to the two cycle-test glyphs (confirmed: nothing else in the
paint graph references them). Regenerated by dropping just those two
BaseGlyphPaintRecord entries and re-saving, verified clean via
`ots-sanitize` afterward.

Regenerate via:

python3 -c "
from fontTools.ttLib import TTFont
f = TTFont('assets/test-fonts/colr-v1-test-glyphs/test_glyphs_variable.ttf')
bgl = f['COLR'].table.BaseGlyphList
bgl.BaseGlyphPaintRecord = [r for r in bgl.BaseGlyphPaintRecord
    if r.BaseGlyph not in ('paintcolrglyph_cycle_first', 'paintcolrglyph_cycle_second')]
f.save('assets/test-fonts/test-fixtures/test_glyphs_variable_no_cycle_test_glyphs.ttf')
"

Used by: the fuzzer, which seeds from every fixture; no test names it.

carets.ttf, hinted.ttf, colr-clip.ttf, gvar-points.ttf and the three cff-*.otf
are neither vendored nor derived – they are synthetic, built from nothing by
daegun's own scripts, and carry no third-party content at all. All are MIT
with the rest of the project.

carets.ttf        scripts/tools/oracles/diff/build_caret_fixture.py
                  Family name "DaegunCarets". A GDEF LigCaretList with
                  known caret positions, so caret geometry can be asserted
                  against numbers the fixture itself defines rather than
                  against whatever a real font happens to contain.
                  Used by: src/daegun/tests/api/surface_glyphs.rs and
                  the C round trip.

hinted.ttf        scripts/tools/oracles/diff/build_hinted_fixture.py
                  Family name "DaegunHinted". Carries real TrueType
                  bytecode (fpgm/prep/glyf instructions) so the interpreter
                  is graded on instructions written for it, at sizes chosen
                  to make the v35/v40 difference visible.

                  Glyphs A-D aim one opcode family each: A rounds a stem
                  horizontally (so v35 and v40 differ on it), B branches on
                  ppem through IF/ELSE/EIF, C jumps backward via LOOPCALL,
                  D carries no instructions at all as the control.

                  E and F are a pair, and only mean anything together. E
                  redefines fn 0 inside its own glyph program as MDAP[0] –
                  touch without rounding, the opposite of fpgm's fn 0. F
                  carries A's program byte for byte over A's box. So F must
                  hint identically to A whether or not E ran first, and a
                  glyph-level FDEF that outlives its glyph makes F quietly
                  stop rounding, which fonts that keep every FDEF in fpgm,
                  where none of them leak, never show.
                  Used by: src/daecore/tests/type/fdef_scope.rs,
                  hint_latency.rs and hint_threading.rs, the fingerprint
                  suite, the hinting unit tests, src/daegun/tests/api/
                  autohint.rs, access.rs, prepared.rs and
                  surface_glyphs.rs, and the C round trip.

colr-clip.ttf     scripts/tools/oracles/diff/build_colr_clip_fixture.py
                  Family name "DaegunColrClip". Color glyphs no vendored
                  font has: N and C paint one glyph through another, so
                  their scenes clip; D nests 64 composites, as deep as a
                  paint graph parses; S has 255 layers share one gradient
                  of 4,000 stops; L's first layer is itself a layer list,
                  as fontTools' layer reuse writes; and three COLR v0
                  glyphs, P layering 17 composites of 64,000 points (past a
                  scene's limit), R one composite eight times, F a layer in
                  the text color.
                  Used by: src/daegun/tests/api/surface_glyphs.rs and
                  colr_v0.rs, the C round trip, and the fuzzer, which seeds
                  from every fixture.

gvar-points.ttf   scripts/tools/oracles/diff/build_gvar_fixture.py
                  Family name "DaegunGvarPoints". One wght axis and a gvar
                  laid out byte by byte, since fontTools rewrites any gvar it
                  compiles: point lists with repeated and out-of-range
                  numbers, a list longer than its glyph, phantom deltas on a
                  simple glyph and on a composite.
                  Used by: src/daegun/tests/api/gvar_points.rs.

cff-subrs.otf     scripts/tools/oracles/diff/build_cff_subset_fixtures.py
cff-cid.otf       (one script writes all three into the directory given)
cff-expert.otf    cff-subrs: name-keyed, global and local Subrs, a full Top
                  DICT, and seacs bare, after a hint and inside a
                  subroutine. cff-cid: CID-keyed, two FDs with their own
                  Subrs and FontNames, FDSelect format 3, and a seac whose
                  components no CID-keyed font can name. cff-expert: the
                  predefined Expert charset.
                  Used by: src/daegun/tests/api/cff_subset.rs and the
                  subsetter's CFF unit tests.

Regenerate any of them by running its script; each takes an output path (the
CFF script a directory).

assets/test-fonts/Irianisadfstd/*.ttc are NOT derived fixtures – they're real,
independently-sourced TTC files (Arkandis Digital Foundry, Irianis ADF,
GPL v2+ with font exception – free/redistributable, same freedom class as
the other bundled fonts) used as-is, referenced directly from
assets/test-fonts/Irianisadfstd/ rather than copied here. Each is a genuine
2-font collection where both members are STATIC (no fvar at all) and share
identical glyf data under two different family names – the real-world case
EBGaramond-InterVariable.ttc above can't cover, since its own EBGaramond
member is a variable build, not the static standalone EBGaramond.ttf. Used
by: the fuzzer, which seeds from every font here; no test names them.
